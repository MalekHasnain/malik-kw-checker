New here? Install & get started ↓
  1. Open the GitHub repository and choose Code → Download ZIP.
  2. Extract the ZIP to a permanent folder.
  3. Enter chrome://extensions in Chrome and turn on Developer mode.
  4. Click Load unpacked. Select the extracted folder containing manifest.json.
  5. Pin Malik Kw Checker from Chrome’s puzzle menu. Add your Ahrefs key below and save.

Already installed? You’re ready to configure your sources. Site Age needs no API key.
